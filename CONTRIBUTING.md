# Como contribuir

**Português** · [English](#english)

Sugestões e correções são bem-vindas. A Pandora Box é a base de conhecimento aberto da Pandora Tech, mantida pela equipe da Pandora.

## Formas de contribuir

- **Encontrou um erro ou tem uma dúvida?** Abra uma [issue](../../issues/new/choose).
- **Quer sugerir um conteúdo?** Abra uma issue do tipo "Sugestão de conteúdo".
- **Quer corrigir algo?** Faça um fork, edite e abra um pull request.

## Convenções

- Conteúdo em **português do Brasil**, com a versão em inglês abaixo nas páginas principais.
- Frases curtas e afirmativas. Sem emoji nos textos.
- Nomes de arquivos e pastas em `kebab-case`, sem acentos: `como-criar-uma-mcp.md`.
- Cada pasta tem um `README.md` com o índice. Ao adicionar algo, atualize o índice.
- Use os modelos em `mcps/_modelo/` e `skills/_modelo/`.
- Skills ficam em `skills/<família>/<skill>/SKILL.md`, com uma página `README.md` na mesma pasta.

## Segurança

Este repositório é **público**. Nunca faça commit de:

- chaves de API, tokens, senhas ou arquivos `.env`;
- dados de clientes ou informações pessoais;
- endereços internos ou credenciais de qualquer tipo.

Use sempre `.env.example`, com os campos vazios.

# How to contribute

**English** · [Português](#como-contribuir)

Suggestions and fixes are welcome. Pandora Box is Pandora Tech's open knowledge base, maintained by the Pandora team.

- **Found a mistake or have a question?** Open an [issue](../../issues/new/choose).
- **Want to fix something?** Fork, edit and open a pull request.
- **Conventions:** Brazilian Portuguese first, English below on main pages; short sentences, no emoji; `kebab-case` file names; update the folder's `README.md` index; skills live in `skills/<family>/<skill>/SKILL.md` with a `README.md` page.
- **Security:** this repository is public. Never commit API keys, tokens, passwords, `.env` files, customer data or personal information. Use `.env.example` with empty values.
