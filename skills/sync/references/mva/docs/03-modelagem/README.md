# 03 — Modelagem do problema
**Objetivo:** construir a arquitetura do problema antes da arquitetura da automação.

**Sessão:** 60–90 minutos com facilitador e pessoas que vivem o processo.

## Saídas
1. fluxo atual;
2. mapa de influências;
3. mapa de contexto;
4. hipótese inicial de automação orientada pela experiência.

> A arquitetura da automação não vem antes da arquitetura do problema.
