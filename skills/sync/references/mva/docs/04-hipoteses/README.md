# 04 — Hipóteses e refinamento técnico
**Objetivo:** transformar a hipótese orientada pela experiência em hipótese(s) tecnicamente experimentáveis.

**Responsável:** time de inovação/automação com conhecimento do processo.

**Analisar:** dados/contextos, ferramentas, integrações, restrições, riscos, partes humanas, métricas e o menor experimento capaz de produzir evidência útil.

**Saída:** hipótese(s) técnica(s) rastreáveis ao problema original.
